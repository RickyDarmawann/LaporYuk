# LaporYuk
Sistem pelaporan kerusakan fasilitas kampus (jalan berlubang, lampu mati,
tempat sampah rusak, dll). Tugas UAS Pemrograman Terstruktur (Python).

## Status Pengerjaan
- [x] Progress 1: Struktur proyek dan class Laporan
- [x] Progress 2: Validasi input (validasi.py)
- [x] Progress 3: File handling CSV (storage.py) dan data awal 20 laporan
- [x] Progress 4: Searching (linear), sorting (bubble), *args, **kwargs, lambda (services.py)
- [x] Progress 5: Unit test dengan unittest (tests/test_services.py)
- [x] Progress 6: Tampilan GUI Tkinter (ui.py, main.py)

## Menjalankan Unit Test
    python -m unittest discover -v

## Menjalankan Aplikasi
    python main.py
